= Automated Video Showcase & Multi-Language Audio Narration Architecture
:author: Copyright (c) KriolOS Team.
:toc:
:toc-placement!:
:icons: font

Technical specification and architectural guide for generating synchronized video showcases with multi-language voiceover narration directly from automated UI robot tests.

toc::[]

== 1. Executive Summary & Vision

Software demonstrations, tutorial videos, and marketing releases for modern retail POS applications usually require tedious, error-prone manual screen recording and voiceover editing. When marketing to diverse regions (e.g. Portuguese-speaking markets such as Brazil, Portugal, Cape Verde, Angola, and Mozambique, alongside international English-speaking markets), creating separate video assets manually doubles the production burden.

`kriolos-opos-automation` introduces an **automated end-to-end video and multi-language audio narration pipeline**. As UI robot integration tests (`BasePosRobotIT`) execute functional flows (login, sales, inventory, close cash, configuration), the system:
1. Records crisp H.264 video of the application in memory.
2. Resolves localized explanation scripts from externalized properties bundles.
3. Synthesizes voiceovers in multiple languages simultaneously.
4. Mixes audio tracks on a precise timeline in pure Java (`javax.sound.sampled`).
5. Assembles single-language MP4 videos (`session_pt.mp4`, `session_en.mp4`) as well as a **YouTube-compliant dual-audio video** (`session_youtube_multilingual.mp4`).

== 2. Comparison of Existing Solutions

[cols="2,2,2,3", options="header"]
|===
| Approach | Multi-Language Support | Platform Portability | Trade-offs & Analysis

| **Manual Video Recording & Voiceover**
| ❌ High effort per language
| N/A (Manual human labor)
| Requires OBS/Kdenlive, manual dubbing, and re-recording every time the UI changes.

| **OS Native CLI Synthesizers** (`RHVoice`, `say`, `SAPI`)
| ✅ High quality native voices (e.g. `Leticia-F123` for PT, `slt`/`bdl` for EN)
| ⚠️ Platform-specific binaries
| Zero latency, no network cost, but requires binary packages installed on host. Ideal for local dev and release generation workstations.

| **Pure Java Synthesizers** (MaryTTS, FreeTTS)
| ⚠️ Variable voice naturalness
| ✅ 100% JVM Portable
| Runs on any JDK without native binaries. MaryTTS supports modular languages (EN, DE, FR, IT), though voice packages add ~30-50MB dependencies. FreeTTS is primarily limited to US English.

| **Cloud TTS Services: Azure Neural Speech (`AzureTtsEngine`)**
| ✅ Studio-grade broadcast naturalness (`pt-PT-RaquelNeural`, `en-US-AriaNeural`)
| ✅ 100% JVM Portable (HTTP REST)
| Generates broadcast/documentary-grade speech directly into 24kHz PCM WAV via Azure Cognitive Services. Configurable via `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION`.

| **Edge Neural Speech (`EdgeNeuralTtsEngine`)**
| ✅ Studio-grade naturalness (`pt-PT-RaquelNeural`, `en-US-AriaNeural`)
| ✅ Automatic Managed Venv (`target/tts-env`)
| Uses Microsoft Edge's Neural Speech protocol. Zero API keys, completely free, pristine broadcast-quality Portuguese and English voices.

| **Synthetic Pure Java Fallback** (`MockJavaTtsEngine`)
| ✅ Synthetic audio markers
| ✅ 100% JVM Portable
| Generates clean algorithmic WAV cues via `javax.sound.sampled`. Guarantees automated test suites pass on any headless CI runner without external audio software.

| **FFmpeg `adelay` + `amix` Filters**
| ⚠️ Complex command syntax
| ⚠️ Requires external FFmpeg CLI
| Spawns external processes, susceptible to pipe deadlocks when command-line buffer limits are exceeded.

| **Pure Java Timeline Mixer (`JavaAudioTimelineMixer`)**
| ✅ Unlimited channels & clips
| ✅ 100% JVM Portable (`javax.sound.sampled`)
| Direct in-memory PCM mixing (24kHz/44.1kHz 16-bit). Performs sample addition with clipping protection (`Short.MIN_VALUE` to `Short.MAX_VALUE`). High performance (<5ms).

| **Embedded FFmpeg via Maven (`ws.schild:jave-all-deps`)**
| N/A (Video / Audio Tooling)
| ✅ Automatic Cross-Platform Extraction
| Bundles pre-compiled FFmpeg binaries for Linux (x64, arm32, arm64), macOS (Intel, Apple Silicon), and Windows (x86, x64). Resolved automatically by `FfmpegLocator` without requiring system package managers.

| **JavaCV & OpenCV (`bytedeco/javacv`, `actimem/pilecv4j`)**
| N/A (Computer Vision / Frame Pipelines)
| ⚠️ Heavy multi-platform native jars
| Provides Java bindings to OpenCV and FFmpeg (via JavaCPP). Highly suited for real-time computer vision and image processing pipelines, though dependency footprints can exceed 300MB+.

| **Embedded Swing VLC Player (`caprica/vlcj`)**
| ✅ Hardware-accelerated multi-track playback
| ⚠️ Requires host LibVLC
| Embedded hardware-accelerated Swing canvas panel (`VlcVideoPlayerPanel`). Enables developers to preview recordings, scrub timelines, inspect timecodes, and toggle multi-language narration tracks directly inside Swing.
|===

== 5. Core Components & Implementation

=== 5.1 `TtsEngine` SPI

[source,java]
----
public interface TtsEngine {
    String getName();
    boolean isAvailable();
    File synthesize(String text, Language language, File outputWav);
}
----

* **`AzureTtsEngine`**: Microsoft Azure Cognitive Services Speech REST API. Delivers studio-grade broadcast speech (`pt-PT-RaquelNeural`, `en-US-AriaNeural`). Configured via `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION`.
* **`EdgeNeuralTtsEngine`**: Microsoft Edge Neural Speech engine. Provides the exact same broadcast neural voices (`pt-PT-RaquelNeural`, `en-US-AriaNeural`) without needing API keys. Automatically bootstraps a project-managed venv under `target/tts-env`.
* **`RhVoiceTtsEngine`**: Native offline synthesizer calling `/usr/bin/RHVoice-test` with `Leticia-F123` (Portuguese) and `slt` (English). Enhanced with `-q best`, `-r 92` (relaxed pacing), `-t 98`, and FFmpeg vocal acoustic post-processing (`equalizer 3kHz -2.5dB`, `lowpass 7.5kHz`, `compand`) to eliminate metallic/robotic rasp.
* **`MockJavaTtsEngine`**: 100% pure Java algorithmic tone generator via `javax.sound.sampled` for offline/CI runners without network or audio binaries.

=== 5.2 Pure Java Timeline Mixing (`JavaAudioTimelineMixer`)

The mixer processes timed clips without spawning external processes:
1. Calculates target sample offset: `startFrame = (long) (offsetMs * (sampleRate / 1000.0))`.
2. Decodes 16-bit PCM little-endian byte buffers into `short[]` arrays.
3. Accumulates overlapping samples into a master timeline buffer with saturation clipping:
+
[source,java]
----
int sum = masterBuffer[startSample + i] + src[i];
if (sum > Short.MAX_VALUE) sum = Short.MAX_VALUE;
else if (sum < Short.MIN_VALUE) sum = Short.MIN_VALUE;
masterBuffer[startSample + i] = (short) sum;
----
4. Writes the continuous output WAV using `AudioSystem.write()`.

=== 5.3 YouTube Multi-Audio Track Standard

YouTube natively supports multiple audio tracks in a single MP4 container if tracks include ISO 639-2 language metadata. The FFmpeg muxer outputs:

[source,bash]
----
ffmpeg -y -i session.mp4 -i narration_pt.wav -i narration_en.wav \
  -map 0:v -map 1:a -map 2:a \
  -c:v copy -c:a aac -b:a 192k \
  -metadata:s:a:0 language=por -metadata:s:a:0 title="Português" \
  -metadata:s:a:1 language=eng -metadata:s:a:1 title="English" \
  -shortest session_youtube_multilingual.mp4
----

When uploaded to YouTube, viewers in Portuguese-speaking regions hear Portuguese by default, while global viewers hear English, with the option to switch languages via the player gear menu.

== 6. Adding a New Language (e.g. Spanish)

To add Spanish (`es`) support:
1. Add `narration_es.properties` in `src/test/resources/narration/`.
2. Register the language in `PosAudioNarrator.Language`:
+
[source,java]
----
ES("es", "spa", "Español", "esperanza");
----
3. The engine automatically discovers the new bundle, synthesizes Spanish audio cues, and generates `session_es.mp4`.

== 7. How to Run

=== 7.1 Running with Auto Discovery (Default)
[source,bash]
----
./mvnw test -f kriolos-opos-automation/pom.xml -Dtest=PosLoginIT
----

=== 7.2 Running with Azure Cognitive Services Neural Speech
[source,bash]
----
./mvnw test -f kriolos-opos-automation/pom.xml -Dtest=PosLoginIT \
  -Dtest.tts.engine=azure \
  -Dazure.speech.key="YOUR_AZURE_KEY" \
  -Dazure.speech.region="westeurope"
----

=== 7.3 Running with Edge Neural Speech (Free Broadcast Quality)
[source,bash]
----
./mvnw test -f kriolos-opos-automation/pom.xml -Dtest=PosLoginIT -Dtest.tts.engine=edge
----

=== 7.4 Running with RHVoice (Offline Native Engine)
[source,bash]
----
./mvnw test -f kriolos-opos-automation/pom.xml -Dtest=PosLoginIT -Dtest.tts.engine=rhvoice
----

Generated artifacts in `target/recordings/pos_login_run/`:
* `session.mp4` (Raw video)
* `session.gif` (Animated GIF showcase)
* `session_pt.mp4` (Portuguese narrated video)
* `session_en.mp4` (English narrated video)
* `session_youtube_multilingual.mp4` (Dual-track YouTube video)

== 8. VLC Swing Demo Player Panel (`VlcVideoPlayerPanel`)

`kriolos-opos-automation` includes an embedded Swing video player panel powered by link:https://github.com/caprica/vlcj[vlcj 4.8.3].

=== Features
* **Embedded Swing Canvas**: Hardware-accelerated rendering directly inside a `JPanel`.
* **Transport Controls**: Play, Pause, Stop, Seek Slider with millisecond precision.
* **Multi-Language Audio Track Switching**: Live combo box enabling users to switch between Portuguese and English audio tracks in `session_youtube_multilingual.mp4`.
* **Volume Slider**: Real-time 0-100% volume control.
* **Automatic Fallback**: Graceful fallback UI with setup instructions if native LibVLC is not installed on the host.

=== How to Launch the VLC Player

==== A. Automatic Post-Test Playback
Pass `-Dtest.playback.vlc=true` or `-Dopos.playback.vlc=true` to any automation test:

[source,bash]
----
./mvnw test -f kriolos-opos-automation/pom.xml -Dtest=PosLoginIT -Dtest.playback.vlc=true
----

==== B. Standalone Demo Launcher
Run the standalone launcher passing the path to any recorded video:

[source,bash]
----
# Run via Maven test runner
./mvnw test -f kriolos-opos-automation/pom.xml -Dtest=VlcPlayerDemoTest -Dtest.playback.vlc=true

# Or run directly via Java main class
java -cp ... io.github.kriolos.opos.automation.video.VlcVideoPlayerPanel target/recordings/pos_login_run/session_youtube_multilingual.mp4
----
